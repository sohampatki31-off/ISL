How Detection Works

From camera pixels to a spoken sentence — the stages the video feed passes through on every frame, and the model behind the classifier on Page 1.

DETECTION PIPELINE
01
📷
Camera Input
Live video frames captured from the webcam feed.
MJPEG stream
02
🖐️
Hand Landmark Detection
MediaPipe HandLandmarker locates up to 2 hands, 21 landmarks each.
MediaPipe Tasks
03
〰️
One-Euro Smoothing
Per-landmark filter removes jitter while keeping fast motion responsive.
β = 12.0
04
🧮
Feature Extraction
Smoothed landmarks become a fixed-length numeric vector for the classifier.
132 features
05
🌲
RandomForest Classifier
Predicts the most likely letter/sign and a confidence score.
200 trees
06
⏱️
Stability Gate
A sign must hold steady for several consecutive frames before it locks in — filters out flicker between gestures.
8-frame debounce
07
✍️
Word / Sentence Composer
Locked letters build a word; word-gestures and suggestions build the full sentence.
Live on Page 1
08
🔊
Speech Output
The finished sentence is read aloud via the browser's speech synthesis.
Web Speech API
